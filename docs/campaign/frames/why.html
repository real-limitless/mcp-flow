The failure mode we refuse

Every laptop becomes a secret store.

Vendor API keys in Cursor JSON. MCP sprawl no one can inventory. Prompt injection that only needs one leaked header. That is not an enterprise control plane.

Without a gateway

  • Each harness holds x-api-key / Bearer tokens in plain config
  • Shadow MCP lists — no shared library, no revoke path
  • Rotate a vendor key → chase every developer machine
  • Tools and secrets both sit next to the model context

With mcp-flow

  • Admins seal upstream headers/env once — AES-256-GCM at rest
  • Employees get hashed agent keys; plaintext shown once
  • One workspace library for Cursor, Claude, OpenCode, OpenFlow
  • GET/list redacts secrets; proxy injects only on outbound calls
Why you need it
You want agents with a full tool library — not a fleet of unmanaged API keys on every IDE.
